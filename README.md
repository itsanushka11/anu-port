# Anushka — Portfolio

> Business Analytics · Finance · Generative AI

A modern, interactive portfolio website built with React, TypeScript, and Vite.

## Live Demo

🔗 [View Portfolio](https://subhamkumar.github.io/anu-port/)

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** — Fast build tool
- **Custom CSS** — Nexus design system

## Features

- Interactive particle background with mouse tracking
- Typing animation in hero section
- 3D tilt effect on cards
- Animated number counters
- Scroll-triggered reveal animations
- Responsive design
- Dark theme with glassmorphism

## Sections

- Hero with typing animation
- Stats with animated counters
- About + Contact
- Education (Timeline)
- Skills (Animated bars)
- Projects (3D tilt cards)
- Certificate
- Achievements

## Getting Started

```bash
cd portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```
